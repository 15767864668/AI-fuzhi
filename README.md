# 红果短剧本地成片工具

Python + Gradio 本地客户端：剧本 → H3 原生带声音视频 → ASS 字幕 → FFmpeg 剪辑混音 → MP4 成片。

支持 MiniMax 官方 H3 V2 和自建 GPU H3 HTTP 服务，使用下拉框切换。项目包含客户端完整代码、测试和示例；不包含 H3 权重、CUDA、GPU 推理服务或 FastAPI 适配器，不需要额外 TTS 或对口型模型，也不会下载或内置 FFmpeg。

H3 通过提示词生成台词、人声和同步嘴型。客户端检查媒体是否有音轨，但不能判断模型是否准确念出了每个字；字幕依据你填写的时间生成，需预览确认口播内容与时间。

## 1. 安装与启动

需要 Python **3.10 或以上**、本机 FFmpeg / ffprobe，以及可显示中文的字体。推荐 Python 3.11 或 3.12。

先在终端确认：

```bash
python --version
ffmpeg -version
ffprobe -version
```

FFmpeg 必须包含 `libass` 字幕支持、`libx264` 和 `aac` 编码器，并支持 `sidechaincompress`、`afftdn`、`alimiter` 滤镜。可用以下命令查看：

```bash
ffmpeg -hide_banner -filters
ffmpeg -hide_banner -encoders
```

Windows PowerShell，在解压后的项目目录运行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe app.py
```

macOS / Linux，在项目目录运行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
.venv/bin/python app.py
```

浏览器打开 **http://127.0.0.1:7860**。程序绑定本机回环地址，不创建公网分享链接。终端保持运行，按 `Ctrl+C` 退出。若端口被占用，在 `.env` 中更改 `HONGGUO_PORT`。将 `HONGGUO_OPEN_BROWSER=0` 可关闭启动时自动打开浏览器。`HONGGUO_DATA_DIR` 支持绝对路径；相对路径基于 `app.py` 所在目录。

FFmpeg 使用你已安装的版本；若不在 PATH，在 `.env` 中指定完整路径：

```dotenv
FFMPEG_BIN=C:/ffmpeg/bin/ffmpeg.exe
FFPROBE_BIN=C:/ffmpeg/bin/ffprobe.exe
```

默认字体是 `Noto Sans CJK SC`。Linux 可安装 Noto CJK 字体；Windows 可将页面字体名称改为已安装的 `Microsoft YaHei`，macOS 可用 `PingFang SC`。填字体族名称，而不是 `.ttf` 文件路径。

## 2. 第一次制作

1. 填写剧本名称，粘贴台词或导入 `examples/demo.txt`，将文本应用到台词表格。
2. 在表格中编辑每段台词、正文开始/结束秒、角色、画面提示词、源视频裁剪起点。自动产生的 ID 用于识别缓存片段，保持不变即可。
3. 输入角色名并上传角色参考图。表格角色名与上传时的名称一致；按需选择 BGM、片头和片尾视频。
4. 选择后端，填写 API Key 或预先配置环境变量。确认模型、生成分辨率、画幅和接口地址。
5. 选择导出模板、字幕样式、音量、降噪及水印参数，点击完整生成成片按钮。
6. 查看实时日志、规格与音频告警，预览片段和成片，下载 MP4、ASS、台词或项目包。

可以先“仅生成片段”，检查后再用已有片段导出。某段不满意时，通过 ID 选择该段并重新生成，再导出成片。**单段重新生成会提交一个新的生成任务，可能产生费用**；普通生成会优先复用有效缓存或继续查询已保存任务。

## 3. 剧本与时间轴

支持 UTF-8 / UTF-8 BOM 和 GB18030 TXT。空行与以 `#` 开头的行忽略。普通剧本每行一段，按页面指定的默认时长依次排列：

```text
这份合同，我不会签。
你终于学会替自己做决定了。
```

含角色和画面提示词时，用 `|` 分隔。含时间时，用方括号：

```text
[0-5] 林夏|这份合同，我不会签。|现代办公室，人物近景。
[5-10] 顾言|你终于学会替自己做决定了。|窗边，转身，平静坚定。
[00:00:12-00:00:17] 林夏|这一次，我要拿回属于我的一切。|目光坚定，镜头缓慢推进。
```

规则：

- 开始/结束是**正文绝对时间**，从 0 秒计算，不包含片头。插入片头后字幕自动整体后移。
- 时间可以是秒数、`MM:SS.mmm` 或 `HH:MM:SS.mmm`；结束必须大于开始，台词按时间递增排列，不允许重叠。
- 段间空隙补黑场和静音；例如上例 10–12 秒是两秒黑场。
- “源视频裁剪起点秒”指定从该 H3 视频何处取画面与原声音轨；台词段时长为 `结束-开始`。
- 官方 H3 基础模型生成时长为 4–15 秒整数，客户端按 `段时长 + 裁剪起点` 向上取整，最少 4 秒。超过 15 秒时需拆段。`MiniMax-H3-Max` 最少 5 秒。
- 源视频短于所需裁剪区间，或正文片段完全没有音轨时，会明确报错。已有音轨较短时会告警并在尾部补静音，必须试听确认台词是否完整；程序不会自动补出缺失台词。
- 时间较短时，H3 生成的台词可能尚未念完就被裁剪；应增加该段时长并重新生成，或更改源视频裁剪点。

## 4. 后端配置

API Key 可在页面密码框输入，也可写入本地 `.env`。页面密码框为空时读取对应环境变量。**不要把真实密钥填入提示词、额外 JSON 参数或项目名称。**

### MiniMax 官方 H3

默认配置：

| 页面参数 | 默认值 |
| --- | --- |
| 后端 | MiniMax官方H3 API |
| 服务地址 | `https://api.minimax.cn` |
| 创建路径 | `/v2/video_generation` |
| 查询路径 | `/v2/query/video_generation/{task_id}` |
| 模型 | `MiniMax-H3` |
| 生成分辨率 | `768P` |
| 画幅 | `9:16` |
| 密钥环境变量 | `MINIMAX_API_KEY` |

使用 V2 多模态 `content` 协议；图像作为 `reference_image`，在客户端读取并转为 Data URL 上传。官方返回 `task_id`，轮询成功后从 `task.content.url` 读取地址，适配器统一转换为 `video_url` 并下载 MP4。

基础模型 `MiniMax-H3` 支持 `768P` / `2K`。Highspeed / Lite / Max 的支持档位不同，客户端进行组合校验。生成分辨率是 H3 请求档位，与最终导出的 720P / 1080P 模板独立；最终视频会按导出参数统一缩放、裁剪或补边。

参考图建议使用清晰、单主体、无遮挡的人物图。客户端支持 JPG / PNG / WEBP；官方输入检查包括单图不超过 30MB、边长 256–5760 像素、宽高比 0.4–2.5、每段最多 9 张图、请求 JSON 不超过 64MB。人物一致性仍取决于模型和素材质量。

官方文档：[创建 H3 视频任务](https://platform.minimax.cn/docs/api-reference/video-generation-v2-create)、[查询任务](https://platform.minimax.cn/docs/api-reference/video-generation-v2-query)。接口字段按编写时所查文档封装；账号可用模型、配额和域名以你所在区域的官方控制台为准，可以在页面中调整。

### 自建 GPU H3 服务

切换后填写 GPU 服务地址；默认 `http://127.0.0.1:8000`，创建路径 `/generate`，查询路径 `/tasks/{task_id}`。GPU 服务应满足下面的 HTTP 契约，适配器需后续单独部署。

创建请求：`POST /generate`，JSON 内容示例：

```json
{
  "model": "MiniMax-H3",
  "prompt": "画面说明及原生中文台词、嘴型同步要求",
  "dialogue": "这份合同，我不会签。",
  "character": "林夏",
  "duration": 5,
  "resolution": "768P",
  "ratio": "9:16",
  "reference_images": ["data:image/png;base64,..."]
}
```

如果已生成完成，直接返回：

```json
{"status": "succeeded", "video_url": "http://127.0.0.1:8000/files/clip.mp4"}
```

异步任务先返回：

```json
{"task_id": "job-001", "status": "queued"}
```

随后 `GET /tasks/job-001` 返回运行状态；完成时返回：

```json
{
  "task_id": "job-001",
  "status": "succeeded",
  "video_url": "http://127.0.0.1:8000/files/job-001.mp4"
}
```

失败时返回 `status: "failed"`；建议携带 `error.message`。状态兼容 `queued` / `running` / `succeeded` / `failed` / `cancelled`；成功状态也接受 `success` / `completed` / `done`。

`video_url` 应是**运行本客户端的机器可以访问的 HTTP/HTTPS 地址**，返回带人声音轨的 MP4。下载请求不携带生成 API 的 Bearer 密钥；如果媒体有访问控制，请返回短期签名下载 URL。服务端不应返回仅 GPU 容器内部有效的文件路径。GPU 服务如启用鉴权，使用页面 GPU API Key 或 `.env` 的 `H3_GPU_API_KEY`，客户端在创建/查询时携带 `Authorization: Bearer ...`。

两个后端都通过统一的 `generate_clip(...)` 函数返回 `video_url`、`local_path`、`task_id`；调用封装在 `hongguo/backends.py` 的 `request_json` 函数中。后续接口协议有变动时，优先调整此模块，无需修改成片逻辑。

### 超时、重试与继续任务

页面可设置单次网络超时、轮询间隔、最长等待时间和额外 JSON 参数，默认分别为 60 秒、5 秒、1800 秒和 `{}`。额外参数用于服务支持的扩展字段，不能覆盖已显示字段或包含密钥。单个下载视频默认限制为 1GiB。

- 付费创建请求只发送一次，不自动重试，避免超时后重复提交。
- 已获得的任务 ID、查询配置和视频地址会写入项目自动保存；轮询或下载失败后再次生成，可以继续查询同一任务。
- 创建请求在返回任务 ID 前超时，服务端是否已接收任务无法由客户端确认；客户端会保留“提交结果不确定”状态并阻止普通生成按钮自动重发。先到服务端核查，再决定是否通过明确的单段重新生成创建新任务。
- 查询与下载对暂时性网络错误有限重试；下载写入临时 `.part` 文件，完成后才替换正式片段。
- 项目保留任务编号不代表服务端永久保留视频或签名 URL；远端任务或下载链接失效时，需要根据服务端能力重新生成。

## 5. 字幕、混音与成片

内置经典白字、高亮黄字、清爽蓝字和红果粗黑描边样式，均含粗体、描边与阴影。可调整字体、字号、底部边距并一键切换。导出的 ASS 使用 Unicode、按输出宽度换行；台词中的 ASS 指令字符会安全转义。

片段先裁剪并统一分辨率、帧率、H.264 / AAC、双声道和采样率，再拼接片头、正文、片尾。画面适配支持居中裁剪或补边。片头/片尾无音轨时自动补静音；正文 H3 视频必须带音轨。

BGM 可选择本地音频，按成片时长循环；BGM 音量独立可调，人声音量可调。开启“人声优先”后，使用侧链压缩在人声出现时压低背景音乐，并以限制器控制混合峰值。降噪开关对原始音轨应用 FFmpeg `afftdn`；建议先预览，以免过度降噪影响音色。关闭 BGM 时保留 H3 原声。

自定义文字水印支持四个角落、字号以及开关，覆盖整条成片。字幕关闭时仍可单独开启水印。

### 导出模板与上传预检

| 模板 | 分辨率 | 帧率 | 视频目标码率 | 音频 |
| --- | --- | --- | --- | --- |
| 红果竖屏·1080P 30帧（建议） | 1080×1920 | 30 | 6000k | AAC 192k，48kHz |
| 红果竖屏·720P 30帧（轻量） | 720×1280 | 30 | 3000k | AAC 128k，48kHz |
| 红果竖屏·1080P 25帧 | 1080×1920 | 25 | 6000k | AAC 192k，48kHz |

这些是面向竖屏短剧的**建议模板，不是红果平台官方认证规格**。上传要求以账号当前后台为准。所有导出参数可在页面修改，宽高必须是偶数。

导出前检查源片段的分辨率、帧率、编码、像素格式、音频采样率与声道；可转换的差异给出提示，并在导出时统一。导出后再次检查，生成可下载的 JSON 检测报告，包含告警与 ffprobe 规格。该校验不能代替平台审核、内容审核或账号权限检查。

音频检测会报告连续静音和接近满幅的疑似削波时间区间。静音可能是剧情停顿；“疑似爆音/削波”是信号阈值检测，不能覆盖所有听感失真，也不能保证台词语义正确。页面会弹出告警并保留日志，供预览确认。

## 6. 项目、队列和文件

“保存项目”导出 `.hgproj` 可搬移项目包，包含剧本、角色图、BGM、片头/片尾、已生成片段和页面参数；不包含 API Key。加载后生成独立项目副本，保留原项目。项目包可能较大，因为缓存 MP4 也在其中。

任务执行过程中自动保存 `projects/autosave.json`。意外退出后，在项目页刷新本机自动保存列表并选择恢复；重新提供密钥，再点击生成按钮继续查询已保存的远程任务或复用成功片段。本机恢复仅读取当前数据目录内受管理的自动保存文件。

需要跨电脑继续编辑时，点击保存并保留 `.hgproj`；加载后重新提供密钥即可。任务失败后也可以保存项目包，保留已成功片段和远程任务编号。若状态是“提交结果不确定”，仍需先去供应商侧核实，不能将恢复当作自动重新提交。台词文本可独立导出，用于写标题和简介。

Gradio 的生成与状态修改事件共用串行队列，后端另有任务锁防止同一数据目录发生处理冲突。支持选取多个 `.hgproj` 文件加入批量任务，逐个执行；具体进度实时显示。批量执行使用页面当前后端配置，开始前请确认服务与密钥。

默认目录结构：

```text
data/
└── <项目ID>/
    ├── characters/    # 角色参考图
    ├── clips/         # H3 下载片段
    ├── subtitles/     # ASS 字幕
    ├── bgm/           # 背景音乐
    ├── media/         # 片头、片尾
    ├── exports/       # MP4 成片、JSON 检测报告
    ├── projects/      # 自动保存 JSON、.hgproj 项目包、台词 TXT
    └── logs/          # 运行日志
```

素材上传后复制进项目目录；只删除浏览器临时上传文件不会破坏已复制素材。成片自动命名为 `剧本名称_YYYYMMDD_001.mp4`，同日序号递增，不覆盖已有成片。日期使用客户端所在机器的本地日期。

### 常见问题

- **缺少 FFmpeg 或字幕滤镜**：确认 `ffmpeg` / `ffprobe` 可执行，使用带 libass 的完整构建。程序启动或导出时会给出依赖错误。
- **中文字幕方框**：安装中文字体，并把页面字体名称改为已安装的字体族名称。
- **401 / 402 / 429**：分别检查 API Key、账户余额或配额、调用限流。错误消息会隐藏密钥和下载 URL。
- **片段没有声音**：检查后端是否输出带原生人声的 MP4，是否在提示词里清楚提供中文台词；客户端不会额外合成声音。
- **源视频短于台词段**：缩短时间轴/裁剪起点，或增加生成时长；若音轨尾部较短，虽会告警并补静音，仍需确认没有截掉台词。
- **人物或台词不稳定**：改善参考图、明确角色和情绪提示词，选中有问题的片段单独重生，再预览。
- **BGM 太响或人声被压住**：降低 BGM 音量、开启人声优先，再检查 H3 源片段本身的音量。
- **项目加载失败**：仅加载本程序导出的 `.hgproj`；项目包拒绝不安全路径和超限内容。不要手工删掉包内素材。
- **导出速度慢、磁盘空间不足**：统一规格和烧字幕需要重新编码，并产生中间文件；可先选 720P 模板，确保数据目录有足够空间。
